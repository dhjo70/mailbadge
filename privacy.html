MailBadge개인정보처리방침

개인정보처리방침

시행일: 2026년 11월 26일

MailBadge는 개발자 본인이 자신의 Gmail 계정에만 사용하는 개인용 macOS 앱입니다. 이 방침은 MailBadge가 Google 사용자 데이터를 어떻게 다루는지 설명합니다.

읽는 정보

MailBadge는 Gmail API의 https://www.googleapis.com/auth/gmail.metadata 권한으로 다음 정보만 읽습니다.

  • 받은편지함의 안 읽은 메일 수
  • 새로 도착한 메일의 보낸 사람, 제목, 스레드 ID

메일 본문과 첨부파일은 읽지 않으며, 이 권한으로는 읽을 수도 없습니다. 메일을 보내거나 지우거나 바꾸지 않습니다.

정보를 쓰는 방법

읽은 정보는 사용자의 Mac에서 메뉴 막대 숫자와 알림을 표시하는 데에만 씁니다. 알림을 누르면 해당 메일을 Gmail에서 열기 위해 스레드 ID를 씁니다.

저장과 전송

  • MailBadge에는 서버가 없습니다. Google 사용자 데이터를 개발자나 제3자의 서버로 보내지 않습니다.
  • Google 로그인 토큰은 사용자의 Mac 키체인에만 저장합니다.
  • 광고, 분석, 추적 도구를 쓰지 않으며 데이터를 판매하거나 공유하지 않습니다.

Google API 서비스 사용자 데이터 정책 준수

MailBadge가 Google API로 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

MailBadge's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

접근 권한 철회

Google 계정의 서드파티 앱 관리 화면에서 언제든 MailBadge의 접근 권한을 철회할 수 있습니다. 앱을 지우면 키체인에 저장된 토큰도 함께 지울 수 있습니다.
